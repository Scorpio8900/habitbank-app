# HabitBank

**HabitBank** is a minimalist habit tracker designed to help users build positive routines. Built with React, it's perfect for tracking progress, reinforcing streaks, and motivating users daily.

## Features

- Add and track personal habits
- Toggle habits as completed
- Simple and clean UI
- Built with React and Tailwind
- Easy to expand with gamification, notifications, or monetization

## Getting Started

### 1. Clone the repo
```bash
git clone https://github.com/YOUR_USERNAME/habitbank-app.git
cd habitbank-app
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start the dev server
```bash
npm run dev
```

## Build for Production
```bash
npm run build
```

## Deploy

This app is ready to deploy on [Vercel](https://vercel.com). Just import your GitHub repo and click **Deploy**.
